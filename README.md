# Executive Sales Dashboard

## Project Overview
This project focuses on sales data processing, cleaning, analysis, and dashboard reporting using Microsoft Excel.

## Project Worksheets
- **Raw_data:** Original sales dataset.
- **Processing:** Data processing and transformation.
- **Cleaned_data:** Cleaned sales data.
- **Analysis:** Sales analysis.
- **Dashboard:** Dashboard worksheet.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization

## Project Objective
To analyze sales data and organize business insights through an Excel-based dashboard.
